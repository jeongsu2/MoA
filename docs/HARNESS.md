## 2026-10-05 Git 규칙 정착
- 사용자 규칙: PR, 브랜치, 커밋은 쉬운 한국어, 커밋은 최소 단위, Claude는 contributor에서 제외.
- 실패 → 수정: PR #1을 처음엔 문서 6개를 커밋 하나로 올렸음 → 규칙에 맞게 문서별 커밋 6개로 다시 나눠 올림 (내용 동일 확인 후 force-push).
- 주의: 세션 기본 git 설정이 Claude 이름이라, 레포에서 작성자를 사용자 정보로 덮어써야 함.

## 2026-10-12 Phase 1-3 (인증, 이미지 저장, 실시간 반영)
- 방법: OWASP 치트시트, Spring, AWS, MDN 공식 문서로 근거를 잡고, MoA 특성(인스타 유입, 오픈 순간 버스트, 5분 카운트다운)에 맞춰 옵션을 비교.
- 발견: 세션 공유, JWT 블랙리스트, SSE 다중 서버가 모두 Redis로 모여서, Redis 도입 시점을 1-2와 묶어 한 번에 결정하도록 정리.
- 결정: 인증 세션(D-16), 이미지 로컬 시작(D-17). 실시간은 사용자가 더 자세한 비교를 요청해 보충 문서(03b)를 작성. 500명 동시 접속 가정으로 방식별 요청 수를 계산해 비교.
- 결정: 실시간은 짧은 폴링으로 시작해 측정 후 결정(D-18). Phase 1 리서치 완료.
