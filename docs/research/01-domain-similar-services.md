# Phase 1-1. 도메인과 유사 서비스 리서치

> 2026-10-05 · 대상: MoA(모아) · 입력: [requirements.md](../requirements.md)

## 1. 도메인 핵심 키워드
| 키워드 | 한 줄 정의 |
|---|---|
| 소셜 커머스 / 댓글 커머스(Comment Selling) | SNS 게시물·라이브에 **정해진 키워드로 댓글**을 달면 주문이 되는 판매 방식. MoA의 원형 |
| 링크인바이오(Link-in-bio) | 프로필 링크 하나로 판매 페이지·주문서로 보내는 방식 (리틀리, 인포크링크, Linktree) |
| 공구(공동구매) | 인플루언서가 기간·수량을 정해 팔로워에게 판매. 재고가 여러 개라는 점이 플리마켓(대부분 1점)과 다름 |
| 웨이트리스트(Waitlist) | 품절 시 대기 명단. MoA의 **차순위 승계**와 같은 개념 |
| 장바구니 만료(Cart expiration) | 담아둔 상품을 일정 시간 안에 결제하지 않으면 풀어주는 규칙. MoA의 **5분 제한**과 같은 개념 |

## 2. 유사 서비스 비교

| 서비스 | 방식 | 결제 | 선착순·품절 처리 | MoA와의 차이 |
|---|---|---|---|---|
| **네이버 블로그 플리마켓** (첨부 캡처) | 글에 번호 붙인 상품, 댓글로 번호 → 판매자가 손으로 대댓글 | 무통장, 비밀댓글로 주소 | 판매자가 눈으로 판정, 3분 지나면 "다른 분께" | MoA가 자동화하려는 원래 방식 |
| **CommentSold** (미국) | `SOLD 상품코드 수량 옵션` 형식 댓글 → 자동으로 장바구니 | 카드 결제(계정 페이지에서) | 품절 시 웨이트리스트, **댓글 수정 불가**(새 댓글 필요), **가입 필수** | 다품목·재고 다수, PG 결제 전제 |
| **Soldsie** (미국, 2012~) | 페이스북·인스타 게시물에 "Sold" 댓글 → 인보이스 발송 | 카드 | 백엔드가 주문 추적 | 플랫폼 댓글에 기생 → API 정책 변화에 취약 |
| **Sprii 류 댓글 판매 툴** | 키워드 댓글 감지 → DM으로 결제 링크 | PG | 1인당 최대 수량, 재고 0이면 자동 마감, 웨이트리스트, 미결제 리마인드 | 외부 SNS 위에서 동작 |
| **스룩페이** (국내) | SNS용 간편 주문서·결제 링크 | 카드·휴대폰·가상계좌 | 주문서 단위 재고 | 선착순 댓글 개념 없음, 주문서형 |
| **리틀리 / 신청폼형** (국내) | 링크인바이오 + 신청폼(성함·연락처·주소·입금자명) | 무통장 → 마감 후 **명단과 입금 내역 대조** | 최소·최대 수량 사전 공지 | 선착순 자동 판정 없음 |

## 3. 공통 패턴 (MoA가 가져올 것)
1. **가입 필수 + 계정에 주문 정보 보관** (CommentSold): MoA의 D-01, D-10과 같은 방향. 댓글에 개인정보를 쓰지 않게 한다.
2. **정해진 댓글 형식** (`SOLD AA 1 blue`): 형식이 엄격할수록 기계 판정이 쉽다. MoA의 "번호 + 제품명 정확 기재"(R-04)의 근거.
3. **웨이트리스트 = 차순위 승계** (D-04), **장바구니 만료 = 5분 제한** (D-07): 해외 서비스는 품절·미결제를 상태 전이로 다룬다.
4. **재고 0이면 자동 마감, 1인당 수량 제한**: 플리마켓은 상품이 대부분 1점이라 "재고 1"의 특수한 경우로 볼 수 있다.
5. **무통장 입금은 명단 대조** (신청폼형): MoA의 실명 대조(D-05)와 같은 방식. 국내에서는 흔한 운영 방식이다.

## 4. MoA만의 차별점
- 외부 SNS 댓글이 아니라 **자체 웹앱 안의 댓글**이다. Soldsie처럼 SNS API 정책에 흔들리지 않고, 댓글 수신 순서를 우리 서버가 **직접 결정**할 수 있다.
- 다품목·다재고가 아니라 **1점 상품의 선착순**이 핵심이다. 그래서 "동시에 들어온 댓글 중 정확히 한 명"을 고르는 문제가 더 날카롭다.

## 5. 리서치에서 새로 나온 질문 (requirements.md에 추가할 후보)
| ID | 질문 | 근거 |
|---|---|---|
| R-14 | 댓글 **수정·삭제**를 허용하나? 당첨 후 수정하면? 오타 댓글을 수정해서 정답으로 바꾸면 순서는? | CommentSold는 수정 불가, 새 댓글 필요 |
| R-15 | 상품 재고는 항상 1개인가, 수량을 둘 수 있나? (같은 에코백 3개) | 공구형은 다수량, 플리마켓은 대부분 1점 |
| R-16 | 1인당 구매 제한을 두나? (한 사람이 여러 상품을 동시에 당첨) | Sprii의 1인당 최대 수량 |
| R-17 | 가입 시 **개인정보 수집·이용 동의**, 판매자에게 구매자 정보 **제3자 제공 동의**가 필요 | 개인정보보호법. 신청폼형 서비스도 동의 체크를 받음 |
