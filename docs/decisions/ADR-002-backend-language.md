# ADR-002. 백엔드 언어: Java + Spring Boot

- 날짜: 2026-10-05, 결정자: 정수, 상태: 확정
- 개발 도구: IntelliJ

## 결정
백엔드는 Java와 Spring Boot로 만든다. (Spring Boot, Java 버전은 ERD 기술 선택에서 정한다.)

## 이유
- 목표가 50명 이상 회사의 백엔드 면접이고, 국내 그 규모 회사 백엔드는 대부분 Java/Kotlin Spring을 쓴다.
- 면접 질문 풀이 크고 정형화되어 있다 (트랜잭션, JPA, 영속성 컨텍스트, 스프링 빈).
- MoA의 핵심인 선착순 동시성 제어 자료가 가장 많다 (`@Transactional`, 비관적/낙관적 락, Redisson 분산 락).

## 버린 대안
- **Python (FastAPI/Django):** 코드가 짧아 초반 개발이 빠르지만, 일반 백엔드 채용과 면접 질문 풀이 상대적으로 작고 동시성 제어 한국어 사례가 적다.

## 리스크
- 설정과 코드량이 많아 초반 진도가 느리다 → 기능 단위로 작게 나눠 진행한다.
- 처음 받은 코드 컨벤션이 Python 기준이었다 → `docs/CONVENTIONS.md` 백엔드 부분을 Java 표준으로 다시 썼다.

## 면접 질문 예시
"왜 Spring을 골랐고, 같은 기능을 Python으로 만들었다면 무엇이 달라졌을까요?"
